## 当前版本

4.1.3 / 413 测试版。包含三款桌面图标（第 2 款默认），入口位于设置 → 风格工坊末尾。包括 User 设定目录推送和阶段说明、阅读预览资源清理。

## 构建

需要 JDK 17、Android SDK 34；运行 `bash gradlew assembleDebug`。2026-11-18 已通过本机 Gradle Debug 构建（BUILD SUCCESSFUL）。ARM Linux 环境需提供可运行的 AAPT2，例如追加 `-Pandroid.aapt2FromMavenOverride=/usr/bin/aapt2`；路径仅为本机示例。尚未在全新电脑环境复验。发行 APK 使用独立的本地签名构建流程，不能声称此工程已经复现发行包。

自行构建使用自己的签名，无法覆盖维护者签名的发行版。维护者签名密钥不随仓库提供。

## 数据与备份

卡片与设置主要保存在本机 WebView IndexedDB；卸载、清除应用数据可能删除数据。升级前建议导出备份。用户导入资源不随源码分发，也不因使用本软件而获得额外授权。

## 平台范围

目前主要面向 Android。目录授权、原生文件读写、桌面图标切换等依赖 Android 桥接。仓库包含 HTML，但不代表 iOS / 桌面网页版已经适配验收。

应用内自动检查和下载更新尚未接入。GitHub 发布渠道与版本信息文件仅是后续实现的基础。
