## 开发者构建

需要 JDK 17、Android SDK 34，在项目目录执行：

```bash
bash gradlew assembleDebug
```

本机 ARM64 Ubuntu 已通过 Debug 构建，以及 4.1.4 Release 构建和 `lintVitalRelease`。ARM Linux 需提供可运行的 AAPT2，例如追加 `-Pandroid.aapt2FromMavenOverride=/usr/bin/aapt2`；该路径仅为本机示例。尚未在全新电脑环境复验。

自行构建使用自己的签名，无法覆盖维护者签名的发行版。维护者签名密钥不随仓库提供。
